Put these font files in this folder (TrueType .ttf or .otf). All are free Google Fonts
or open-source fonts. Download them, then copy the files here.

  Montserrat            Regular, SemiBold, Bold, ExtraBold      (business card text)
  Gelasio               Regular, Bold                           (matches the "Serif" option, same widths as Georgia)
  Arimo                 Regular, Bold                           (matches the "Sans" option, same widths as Arial)
  Cousine               Regular, Bold                           (matches the "Typewriter" option, same widths as Courier New)
  Liberation Sans Narrow  Regular, Bold                         (matches the "Condensed" option)

Static files like Montserrat-Bold.ttf work best. The family name is read from the start of
the file name, so keep the original names (Montserrat-Bold.ttf, Gelasio-Regular.ttf, ...).

The server has no system fonts. If this folder is empty, no text can be drawn and the
server stops with an error instead of producing blank artwork.
